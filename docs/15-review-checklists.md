# Hapag Review Checklists

## Product
- [x] Ingredient-to-recipe journey works end to end.
- [x] AI output is structured and readable.
- [x] Budget, time, difficulty, and servings are visible.
- [x] Substitutions and dietary settings affect suggestions.
- [x] User can save and unsave recipes.

## Design
- [x] Ube and mango palette is used consistently.
- [x] Typography and spacing follow the system.
- [x] Mobile layout works at 320px width.
- [x] Loading, empty, error, and success states exist.
- [x] Copy feels friendly and Filipino.

## Engineering
- [x] OpenAI key is server-side only.
- [x] Supabase RLS protects user data.
- [x] Inputs are validated and AI output is handled defensively.
- [x] Errors and rate limits have user-friendly fallbacks.
- [x] Core flow has tests and a production build succeeds.
