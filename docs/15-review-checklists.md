# Hapag Review Checklists

## Product
- [ ] Ingredient-to-recipe journey works end to end.
- [ ] AI output is structured and readable.
- [ ] Budget, time, difficulty, and servings are visible.
- [ ] Substitutions and dietary settings affect suggestions.
- [ ] User can save and unsave recipes.

## Design
- [ ] Ube and mango palette is used consistently.
- [ ] Typography and spacing follow the system.
- [ ] Mobile layout works at 320px width.
- [ ] Loading, empty, error, and success states exist.
- [ ] Copy feels friendly and Filipino.

## Engineering
- [ ] OpenAI key is server-side only.
- [ ] Supabase RLS protects user data.
- [ ] Inputs are validated and AI output is handled defensively.
- [ ] Errors and rate limits have user-friendly fallbacks.
- [ ] Core flow has tests and a production build succeeds.
