# Hapag User Journeys

## Main journey: What can I cook?
1. User opens Hapag.
2. Sees **“Ano’ng ulam?”** and enters ingredients in English, Tagalog, or Taglish.
3. Hapag normalizes ingredients and asks one clarification only when necessary.
4. Ulam AI returns three recipe suggestions with explanations, time, difficulty, servings, and estimated cost.
5. User opens a recipe, adjusts servings, reviews substitutions, and starts cooking.
6. User marks the recipe as cooked and optionally saves it.

## Secondary journeys
- Browse recipes by meal, budget, dietary need, or region.
- Save a recipe and return to it later.
- Convert leftovers into another meal.

## Example
Input: “May itlog, kamatis, sardinas, at pechay ako.”
Suggestions: Sardines with egg and pechay; ginisang pechay with egg; sardine omelet with tomatoes.
