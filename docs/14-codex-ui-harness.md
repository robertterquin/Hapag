# Hapag UI Harness

Use a small route or Storybook-style page to review components in isolation.

## Required fixtures
- Ingredient input with empty, filled, loading, and error states.
- Recipe card with short and long titles.
- Recipe detail with 1, 4, and 8 servings.
- Cost breakdown under ₱100 and over ₱200.
- Dietary and allergy warnings.
- Empty, offline, and AI error states.

## Review checklist
Confirm spacing, contrast, touch targets, keyboard focus, responsive layout, Tagalog copy, and behavior at narrow widths before connecting real data.
