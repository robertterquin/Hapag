# Hapag Product Principles

## Product
Hapag helps Filipino households turn available ingredients into affordable, practical meals.

## Positioning
**May sahog ka? Luto tayo.**

## Principles
1. **Useful before clever** — every recommendation should help the user decide what to cook.
2. **Filipino by default** — use familiar dishes, ingredients, measurements, and Tagalog/Taglish language.
3. **Budget-aware** — show realistic palengke-style estimates and affordable alternatives.
4. **Flexible cooking** — support incomplete ingredient lists, substitutions, serving adjustments, and leftovers.
5. **Warm and playful** — make cooking feel approachable, not intimidating.
6. **Trustworthy AI** — label estimates, avoid unsafe substitutions, and let users correct assumptions.

## MVP success criteria
- A user can enter ingredients and receive useful recipe suggestions.
- A user can open a structured recipe and start cooking quickly.
- A user can adjust servings, view cost, substitute ingredients, and save a recipe.
