# Hapag Typography, Spacing, and Shape

## Typography
- Headings: a rounded display face such as **Plus Jakarta Sans ExtraBold** or **Nunito ExtraBold**.
- Body: **Inter**, **Nunito Sans**, or the chosen system sans-serif.
- Optional handwritten accent: use only for small labels or illustrations, never paragraphs.

## Scale
Display 40/48, H1 32/40, H2 24/32, H3 18/26, body 16/24, small 14/20, label 12/16.

## Spacing
Use a 4px base grid: 4, 8, 12, 16, 24, 32, 48, 64.

## Shape
Buttons and inputs: 14–18px radius. Cards: 20–24px radius. Pills: 999px. Keep corners consistent across the product.
