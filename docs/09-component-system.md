# Hapag Component System

## Core components
Button, icon button, text input, ingredient input, ingredient chip, filter chip, recipe card, recipe badge, cost breakdown, serving stepper, substitution row, step card, timer, toast, modal, tabs, bottom navigation, skeleton loader, and empty state.

## Component rules
- Every interactive control has hover, focus, pressed, disabled, loading, and error states.
- Primary actions use ube; destructive actions use tomato.
- Recipe cards always expose time, difficulty, and estimated cost.
- Ingredient chips support removal with a visible accessible label.
