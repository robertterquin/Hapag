# Hapag Color System

## Core palette: Ube and Mango
- `--color-cream: #FFF8E7` — page background
- `--color-surface: #FFFFFF` — cards and inputs
- `--color-ube: #7651A9` — primary brand and buttons
- `--color-ube-dark: #57347F` — pressed states and strong headings
- `--color-mango: #F6B544` — highlights and badges
- `--color-calamansi: #A8C64A` — ingredient chips and success accents
- `--color-tomato: #E96A4A` — warnings and featured accents
- `--color-ink: #30252B` — primary text
- `--color-muted: #766B70` — secondary text
- `--color-lavender: #EEE5F7` — soft panels

## Usage rules
Use ube for the main action, mango for attention, calamansi for ingredient-related elements, and tomato sparingly. Keep text contrast accessible. Never place ink text directly on saturated ube without checking contrast.
